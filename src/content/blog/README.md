# Blog Richtlinien

## Interne Verlinkung
**WICHTIG:** Jeder neue Blogartikel muss **mindestens 2 interne Links** zu anderen relevanten Blogartikeln auf dieser Website enthalten.

### Regeln für die Verlinkung:
1. Füge am Ende des Artikels (vor einem eventuellen Footer/CTA oder ganz am Schluss) einen Abschnitt namens `### Weiterführende Artikel` hinzu.
2. Der Ankertext der Links **muss** exakt der Name (Titel) oder der URL-Pfad der jeweiligen Zielseite sein.
3. Beispiel-Formatierung:
   ```markdown
   ### Weiterführende Artikel
   * **Lese-Tipp:** [Titel des thematisch passenden Artikels 1](/blog/slug-1/)
   * **Lese-Tipp:** [Titel des thematisch passenden Artikels 2](/blog/slug-2/)
   ```
4. Diese Struktur ist zwingend einzuhalten, um die thematische Relevanz und den PageRank-Fluss innerhalb des Blogs zu stärken (Interne Verlinkung / SEO).
