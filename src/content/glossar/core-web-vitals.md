Die Core Web Vitals (CWV) sind offizielle Rankingfaktoren im Google-Algorithmus. Sie messen nicht, *was* auf der Seite steht, sondern *wie* sich die Seite für den Nutzer anfühlt.

**Die drei wichtigsten Metriken sind:**
1. **Largest Contentful Paint (LCP):** Misst die Ladezeit. Wie lange dauert es, bis das größte sichtbare Element (meist ein Bild oder eine H1-Überschrift) auf dem Bildschirm erscheint? Ziel: < 2,5 Sekunden.
2. **Interaction to Next Paint (INP):** Misst die Reaktivität. Wie schnell reagiert die Seite auf Benutzereingaben (z.B. Klicks auf Buttons oder Menüs)? Ziel: < 200 Millisekunden.
3. **Cumulative Layout Shift (CLS):** Misst die visuelle Stabilität. Verschieben sich Layoutelemente unerwartet (z.B. weil ein Werbebanner spät nachlädt und den Text nach unten drückt)? Ziel: < 0.1.

Ein grünes Dashboard bei den Core Web Vitals (im Chrome User Experience Report - CrUX) garantiert kein Top-Ranking, verhindert aber "Strafpunkte" bei hart umkämpften Suchbegriffen.
